# Comparative Study of Text Classification Algorithms

## 1. Project Overview

This project compares four machine learning algorithms for text classification using the SMS Spam Collection dataset obtained from Kaggle.

The objective is to evaluate the performance of Decision Tree, K-Nearest Neighbours (KNN), Support Vector Machine (SVM), and Naïve Bayes using the same dataset, preprocessing procedure, TF-IDF features, and train-test split.

## 2. Problem Statement

The task is to classify SMS messages into two categories:

- **Ham:** Legitimate, non-spam messages.
- **Spam:** Unwanted or spam messages.

The performance of the four classifiers is evaluated to determine which model is most suitable for this classification task.

## 3. Dataset

- **Dataset name:** SMS Spam Collection Dataset
- **Source:** Kaggle
- **Dataset link:** https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset
- **Text column:** `v2` (message)
- **Label column:** `v1` (class)

The dataset contains labelled SMS messages belonging to the ham and spam categories. The dataset is inspected and prepared before training the classifiers.

## 5. Methodology

The experiment follows these steps:

1. Load the dataset downloaded from Kaggle.
2. Retain the required text and label columns.
3. Inspect missing values and class distribution.
4. Split the data into training and testing sets using an 80:20 ratio.
5. Convert the text messages into numerical features using TF-IDF.
6. Train Decision Tree, KNN, SVM, and Naïve Bayes classifiers using the same training data and features.
7. Evaluate the models using Accuracy, Precision, Recall, and F1-score.
8. Compare the models using a performance graph and confusion matrices.
9. Conduct a what-if experiment by changing the SVM regularization parameter.
10. Identify the best-performing model based on the experimental results.

## 6. Evaluation Metrics

- **Accuracy:** Measures the proportion of correctly classified messages.
- **Precision:** Measures how many messages predicted as spam are actually spam.
- **Recall:** Measures how many actual spam messages are correctly detected.
- **F1-score:** Combines precision and recall into a single metric.

Precision, recall, and F1-score are calculated for the spam class.
